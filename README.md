# Free Assets Catalog

Catálogo de assets grátis coletados da internet.

**Site:** https://arthurpinheirokriger-lgtm.github.io/free-assets-catalog/

Os assets são armazenados como metadados (links para fontes originais gratuitas) para evitar problemas de tamanho e licença.

## Como usar

Acesse o site e navegue ou busque pelos assets. Cada um tem link direto para download ou uso.

## Fontes

- Unsplash, Pexels, Pixabay, OpenGameArt, etc.

Este repositório é atualizado automaticamente para crescer com milhares de assets.
